# 娃衣小筑 · 已连接本机AI后台

双击“启动网站.cmd”，保持终端运行，浏览器访问 http://127.0.0.1:8520 。
本项目依赖 E:\Research\For\bodym-measurement-estimation 中的本机后台，不是可单独分享的纯静态源码。

1. 进入工作台，在档案中上传同一娃娃的正面、左侧面、背面、右侧面，输入真实身高和模型性别分类。不需要体重。正面和左侧面必需；完整四视图3D需要全部四张。
2. 保存档案后可以预测13项尺寸，仅使用原始正面与左侧面。基于真人训练并按身高换算，BJD精度未验证。
3. 描述服装，可附加最多3张衣服参考图，调用此前配置的合聚gpt-image-2进行逐面换装。
4. 默认勾选自动3D：同一轮四张服装图全部完成后上传至Tripo v3，使用v3.1-20260211生成带纹理/PBR模型。可取消勾选先确认服装，再手动生成3D。
5. 拖动旋转、滚轮缩放，也可下载GLB。3D浏览组件需联网加载。3D仅作外观浏览，不保证模型真实物理尺寸或裁衣精度。

数据存放在后台 reports/dollfit 和 reports/wardrobe，刷新不会丢失。密钥通过Windows DPAPI加密存放在后台config目录，不在网页或浏览器保存。
网络请求中断后不自动重发付费生成。Tripo任务编号已保存时可恢复查询；若提交结果不明确，从Tripo控制台复制任务编号后恢复。

目前仅绑定127.0.0.1供本机使用，未部署公网、用户登录或多用户隔离。AI接口按供应商账户计费。
原版静态360页面仍保留，可手动导入GLB；首页设计入口已进入新工作台。
字体授权见 assets/fonts。
